# AGENTS.md

Шаблон фронтенда на Vite. Страница лежит в `index.html`, код в `src/`, статика в `public/`.

## Команды

| Команда | Что делает |
| --- | --- |
| `make install` | Ставит зависимости и git-хуки |
| `make develop` | Запускает dev-сервер Vite |
| `make build` | Собирает проект для продакшена |
| `make lint` | Проверяет код через oxlint и oxfmt и запускает knip |
| `make lint-fix` | Исправляет форматирование и то, что oxlint умеет исправить сам |

## Проверки

`make lint` также проверяет Markdown (`rumdl`), опечатки (`typos`) и workflow GitHub Actions (`jactionlint`). knip ищет неиспользуемые файлы и зависимости и только сообщает о них, решение по находкам принимает человек. Тестов пока нет, `make test` только печатает сообщение. `make install` ставит git-хуки hk, перед коммитом они запускают `make lint`, перед push `make test`.

Перед завершением задачи запусти `make lint`, команда должна проходить.

## Окружение

Инструменты и их версии задаёт `mise.toml`, ставит их `mise install`.
